# Nephilim Website Design System (Swiss Hardware Grid · Matte Pastel Black)

## Visual World & Spatial Architecture
- **Archetype:** Swiss Hardware Datasheet & Real-Time Network Instrumentation Ledger (Teenage Engineering / Leica / Linear Hardware precision).
- **Structural Principle:** Exposed `1px` matte carbon hairlines (`#222222`) dividing a full-bleed `1360px` architectural frame on a warm matte **Pastel Black** canvas (`#141414`). Zero floating rounded cards, zero decorative gradients, zero nested containers, zero eyebrow kickers above headings.

## Typography
- **Display & Interface Sans:** `Schibsted Grotesk` — Tight display tracking (`-0.035em`), high-contrast weight steps (`500`, `600`, `700`), `text-wrap: balance` on headings, `65ch` maximum prose measure.
- **Telemetry & Protocol Mono:** `Martian Mono` — Explicit `tabular-nums` (`tnum`, `zero`) for zero horizontal layout jitter across live 60fps packet counters, hex dumps, and SHA-256 digests.

## Overdrive Mechanics (Native Web APIs)
- **60fps Canvas 2D L2 Packet Oscilloscope:** Real-time dual-channel TX/RX signal waveform and flying Ethernet frame particle stream physically coupled to the interactive Zero-Shift Workbench sliders, lag injectors, and cut switches. Supports interactive cursor crosshair timebase inspection and `RUN / HOLD` trigger freeze.
- **Synchronized 42-Byte Frame & Memory Dissector:** Cross-highlights Ethernet/ARP octets, raw hexadecimal byte offsets, and `#[repr(C, packed)]` Rust FFI struct fields simultaneously on hover, with live packet mutation.
